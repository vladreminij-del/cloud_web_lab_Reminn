
# Електронний журнал

Вебзастосунок, розроблений у межах лабораторної роботи №3
з дисципліни «Хмарні технології та обчислення».

## Мета проєкту
Розробка Flask-вебзастосунку та його розгортання
у хмарному середовищі Render із використанням GitHub.

## Технології
- Python 3
- Flask
- Gunicorn
- GitHub
- Render

## Функціональність
- Головна сторінка з назвою та повідомленням.
- `/api/info` — інформація про застосунок.
- `/health` — перевірка стану застосунку.
- `/api/subjects` — список навчальних предметів.
- `/api/env` — інформація про середовище виконання.

## Приклад даних
Endpoint `/api/subjects` повертає три навчальні предмети:
1. Хмарні технології
2. Бази даних
3. Вебпрограмування

## Запуск локально

Встановлення залежностей:

```bash
pip install -r requirements.txt
```

Запуск застосунку:

```bash
python app.py
```

Локальна адреса: http://127.0.0.1:5000

## Розгортання у хмарі

Платформа: Render

Build Command:
`pip install -r requirements.txt`

Start Command:
`gunicorn app:app`

Публічний URL:
https://cloud-web-lab-reminn.onrender.com
